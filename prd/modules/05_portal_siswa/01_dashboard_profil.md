# Tier 3 - PRD Fitur: Dashboard & Profil Siswa
**Modul:** Modul 5 (Portal Siswa)

## 1. Overview & Objective
Fitur ini adalah halaman pendaratan utama (*landing page*) saat siswa berhasil *login*, serta halaman profil untuk melengkapi data. Tujuannya memberi siswa ringkasan instan tanpa perlu mencari-cari.

## 2. Functional Requirements
| ID | Fitur | Keterangan / Logic | Prioritas |
| :--- | :--- | :--- | :--- |
| FR-5.1.1 | Dashboard Info Utama | Menampilkan: Nama, Program, Cabang, Status Siswa (Aktif/Cuti/Mengundurkan Diri), PIC Konsultan Marketing. | P0 |
| FR-5.1.2 | Tab Ringkasan | Menampilkan *Tab quick links*: Pembayaran Masuk, Sisa Pembayaran, Kehadiran. | P0 |
| FR-5.1.3 | Progress Level Bahasa | Menampilkan indikator visual (grafik/teks) progres level (A1, A2, B1, B2). | P1 |
| FR-5.1.4 | Layanan Status | Menampilkan sekilas status layanan lanjutan (Layanan A2, B1, Passport, Workshop, Visa) dengan status (Belum/Sudah). | P1 |
| FR-5.1.5 | Profil Lengkap | Menampilkan Data Diri Lengkap dan Dokumen Pribadi Lengkap. | P0 |
| FR-5.1.6 | Info PIC | Menampilkan PIC Konsultan dan Admission PIC di halaman Profil. | P1 |
