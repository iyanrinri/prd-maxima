# Tier 3 - PRD Fitur: Akademik & Pembelajaran Siswa
**Modul:** Modul 5 (Portal Siswa)

## 1. Overview & Objective
Halaman bagi siswa untuk memantau kegiatan belajar-mengajar hariannya. Memastikan siswa tahu persis jadwal kelas mereka dan transparansi nilai dari pengajar.

## 2. Functional Requirements
| ID | Fitur | Keterangan / Logic | Prioritas |
| :--- | :--- | :--- | :--- |
| FR-5.3.1 | Info Kelas Saat Ini | Menampilkan: Level saat ini, Kelas, Pengajar, Jadwal umum, Kapitel/Bab, Progres KBM (A1 Lulus, A2 berjalan dst). | P0 |
| FR-5.3.2 | Jadwal Saya | Menampilkan detail jadwal khusus (Contoh: Kelas Berlin, Senin 08.00-12.00), jadwal Ujian (Goethe B1), *Vorbereitung* (Persiapan), dan Evaluasi. | P0 |
| FR-5.3.3 | Rekap Kehadiran | Tabel daftar kehadiran harian (Tanggal, Kelas, Status: Hadir/Tidak Hadir/Sakit/Tanpa Keterangan). | P0 |
| FR-5.3.4 | Nilai & Raport | Menampilkan Nilai keseluruhan dan Raport terperinci per level bahasa. | P0 |
| FR-5.3.5 | Detail Sertifikat Bahasa | Akses *View Only*. Menampilkan Jenis Sertifikat (Goethe, ÖSD), Tingkat, Nilai *Lesen/Hören/Sprechen/Schreiben* dan *Masa Berlaku* untuk tiap nilai tersebut. | P1 |
| FR-5.3.6 | Upload/Download Sertifikat | Kemampuan bagi siswa untuk upload Sertifikat Bahasa PDF (jika terpisah) atau men-downloadnya (maks 5MB). | P1 |
