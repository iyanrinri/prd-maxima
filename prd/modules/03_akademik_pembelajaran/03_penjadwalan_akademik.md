# Tier 3 - PRD Fitur: Master Penjadwalan Akademik
**Modul:** Modul 3 (Manajemen Akademik)

## 1. Overview & Objective
Kalender sentral untuk mengatur seluruh timeline operasional. Dikelola oleh Kepala Akademik / Admin Akademik untuk *plotting* ujian hingga penugasan pengajar pengganti jika ada kendala.

## 2. Functional Requirements
| ID | Fitur | Keterangan / Logic | Prioritas |
| :--- | :--- | :--- | :--- |
| FR-3.3.1 | Manajemen Jadwal Kelas Dasar | Membuat jadwal Kelas Baru (Jam, Hari, Ruangan) dan penetapan hari Libur Nasional/Institusi di kalender. | P0 |
| FR-3.3.2 | Penjadwalan Ujian & Tes | *Plotting* kalender untuk kegiatan non-KBM: Ujian Sertifikasi, Ujian *Remedial*, dan *Placement Test* (Tes Penempatan Level). | P0 |
| FR-3.3.3 | Manajemen Pergantian Pengajar | Fitur *override* untuk memindahkan/mengganti pengajar utama suatu kelas secara sementara (karena sakit/izin) atau permanen tanpa merusak *database* histori kelas sebelumnya. | P1 |
