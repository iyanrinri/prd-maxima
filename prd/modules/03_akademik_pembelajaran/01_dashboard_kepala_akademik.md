# Tier 3 - PRD Fitur: Dashboard & Monitoring Akademik
**Modul:** Modul 3 (Manajemen Akademik)

## 1. Overview & Objective
*Dashboard high-level* bagi Kepala Akademik untuk memantau kesehatan operasional pembelajaran secara keseluruhan (di seluruh cabang), mengevaluasi kualitas kelas, dan mengawasi kedisiplinan serta kinerja pengajar.

## 2. Functional Requirements
| ID | Fitur | Keterangan / Logic | Prioritas |
| :--- | :--- | :--- | :--- |
| FR-3.1.1 | Progres Makro (Keseluruhan & Cabang) | KPI Akademik: Total Siswa Aktif, Kelas Aktif, Pengajar Aktif, Siswa Masuk Bulan Ini, Selesai Level, Rata-rata Kehadiran & Nilai. | P0 |
| FR-3.1.2 | Monitoring Kelas | Tabel rekap kelas aktif: Nama Kelas, Level, Pengajar, Jumlah Siswa, Rata-rata Kehadiran, Progres Belajar, Status Kelas. | P0 |
| FR-3.1.3 | Monitoring Kinerja Pengajar | *Tracking* kinerja tiap pengajar: Kelas yang ditangani, Jumlah Siswa, Kelengkapan Absensi & Nilai (Apakah pengajar rajin input data?), dan Hasil Evaluasi. | P0 |
| FR-3.1.4 | Progress Level Bahasa | Statistik agregat jumlah siswa per level bahasa (Contoh: A1 = 120 Siswa, A2 = 80 Siswa dst). | P1 |
| FR-3.1.5 | Evaluasi Kelas Rutin | Menampilkan rata-rata nilai dan kehadiran per kelas, pencapaian materi, kendala yang dihadapi kelas, serta *feedback* evaluasi pengajar. | P1 |
