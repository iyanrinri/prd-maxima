# Tier 3 - PRD Fitur: Dashboard & Database Admission
**Modul:** Modul 4 (Kelulusan & Admission)

## 1. Overview & Objective
Halaman utama bagi tim Admission untuk memantau status penyaluran seluruh siswa secara sekilas (helikopter *view*) dan mengakses basis data kelengkapan dokumen siswa.

## 2. Functional Requirements
| ID | Fitur | Keterangan / Logic | Prioritas |
| :--- | :--- | :--- | :--- |
| FR-4.1.1 | Dashboard Metrik Admission | Menampilkan total/angka statistik siswa: Aktif, Belum Diproses, Sedang Diproses, Sudah Interview, Sudah Dapat *Vertrag* (Kontrak), Sedang Proses Visa, Visa Granted, Sudah Berangkat, dan Alumni. | P0 |
| FR-4.1.2 | Database Siswa Lengkap | Menampilkan *list* siswa beserta kompilasi dokumen pribadi (Pas Foto, Akta, KK, Ijazah, Transkrip, Paspor, *Lebenslauf* / CV, *Motivationsschreiben*, Video Perkenalan). | P0 |
| FR-4.1.3 | Progres Bahasa & Nilai | Menampilkan ringkasan status akademik: Level bahasa saat ini, Status Lulus/Sedang Belajar. | P1 |
| FR-4.1.4 | Status Rekomendasi Ujian | Menampilkan status kesiapan ujian siswa: Direkomendasikan, Tidak, Lulus, Belum. | P1 |

## 3. Non-Functional Requirements
*   **Search & Filter:** Halaman database siswa wajib memiliki fitur pencarian nama dan *filter* berdasarkan kelengkapan dokumen.
