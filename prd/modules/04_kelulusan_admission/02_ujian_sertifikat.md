# Tier 3 - PRD Fitur: Jadwal Ujian & Sertifikat Bahasa
**Modul:** Modul 4 (Kelulusan & Admission)

## 1. Overview & Objective
Fitur *tracking* bagi tim Admission untuk mencatat jadwal ujian sertifikasi bahasa siswa dan mengelola (CRUD) data sertifikat yang sudah terbit, karena sertifikat ini adalah dokumen mutlak untuk penyaluran *partner*.

## 2. Functional Requirements
| ID | Fitur | Keterangan / Logic | Prioritas |
| :--- | :--- | :--- | :--- |
| FR-4.2.1 | Manajemen Jadwal Ujian | Mencatat Jenis Ujian, Level, Tanggal Pendaftaran, Tanggal Ujian, dan Status Ujian. | P0 |
| FR-4.2.2 | Hasil & Modul Ujian | Mencatat Hasil akhir, rincian Modul Lulus / Modul Gagal, dan Catatan penguji. | P0 |
| FR-4.2.3 | CRUD Sertifikat Bahasa | Form input detail sertifikat: Jenis (Goethe/ÖSD/ECL), Tingkat (A1-B2). | P0 |
| FR-4.2.4 | Rincian Nilai & Masa Berlaku | Input spesifik nilai tiap bagian: *Lesen, Hören, Sprechen, Schreiben* beserta masa berlakunya masing-masing. | P0 |
| FR-4.2.5 | Upload Sertifikat PDF | *Upload file* sertifikat (gabungan PDF, maks 5 MB). | P0 |
